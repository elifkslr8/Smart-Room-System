# Akıllı Oda Sistemi

PIC16F877A tabanlı akıllı oda sistemi projesi.

Bu proje, gömülü sistemler ve Proteus PCB tasarımı konusunda kendimi geliştirmek amacıyla hazırlanmıştır. Sistem içerisinde çeşitli giriş/çıkış birimleri kullanılarak temel otomasyon mantığı uygulanmıştır.

## Özellikler

- PIC16F877A mikrodenetleyici kullanımı
- Sensör ve kontrol yapıları
- LED kontrol sistemi
- Buzzer uyarı sistemi
- Proteus devre simülasyonu
- PCB tasarımı ve 3D görüntüleme

## Kullanılan Teknolojiler

- MPLAB X IDE
- XC8 Compiler
- Proteus 8 Professional
- C Programlama Dili

## Proje Amacı

Bu proje ile:

- Mikrodenetleyici programlama pratiği yapmak
- PCB tasarımı öğrenmek
- Proteus kullanımı geliştirmek
- Gerçek devre mantığını kavramak
- GitHub üzerinde proje yönetimi deneyimi kazanmak amaçlanmıştır.

## Proje Görselleri

Devre şeması, PCB tasarımı ve 3D görüntüler proje dosyaları içerisinde bulunmaktadır.
